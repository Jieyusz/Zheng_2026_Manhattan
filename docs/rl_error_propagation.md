# Model-free RL error propagation: model, figure, and closed-form prediction

Supplementary methods for the error-propagation figure (`error_propagation_supp`,
generated by `scripts/plot_error_propagation_supp.py`). It documents the model-free
reinforcement-learning (RL) benchmark, explains every feature of the figure (including
why some lines are flat), and shows why the RL prediction is an exact, deterministic
closed form rather than a stochastic simulation. Notation follows
`docs/notation_guide.md`: the **traverse index** $b$ is a 1-based integer ($b=1$ is the
first completed traverse); **distance-to-reward** $d$ counts path positions from the
reward ($d=0$ = reward, $d=1$ = nearest decision, increasing toward the start);
corridor indices run 0–21; turn error is $E$ with chance level $0.5$.

The manuscript figure and its condensed Methods/Discussion sentences can be drawn from
Sections 6–7 below.

## 1. Purpose: model-free RL as a null model

Mask A is the P10 linear path graph — 10 corridors and 9 decision holes between the
home and out ports. Animals reduce their corridor and turn errors over successive
traverses. The question is *how*: does error fall in the pattern a simple, local
reward-learner would produce, or in a qualitatively different pattern?

We use tabular, model-free **Q-learning** as the null model. It is the minimal learner
that (i) has no map or model of the maze, (ii) acquires value only where reward has
actually been experienced, and (iii) treats the two travel directions as independent
problems. Comparing the animals against this null isolates three claims, each a column-
wise contrast in the figure:

1. **Pattern.** Model-free RL resolves errors by *backward propagation* from the reward
   (positions nearest the reward become correct first; the low-error frontier steps
   outward one position per traverse). Animals improve across the whole path roughly in
   parallel.
2. **Origin (latent learning).** Model-free RL is at chance on traverse 1 — it has
   experienced no reward yet, and unrewarded exploration teaches it nothing. Animals
   already show low-error positions on their first rewarded traverse.
3. **Mechanism (direction-independence).** Two independent per-direction learners each
   propagate single-ended from their own reward. Animals improve in *both* directions in
   a way that implies shared, bidirectional (map-like) knowledge.

## 2. The model

### 2.1 Task structure

For each Day-1 Mask-A animal we take its trajectory as a chronological sequence of
**journeys**. A journey is a maximal run of leading **sorties** (excursions that return
to the port they started from) followed by one terminating **traverse** (a completed
port-to-port run); it is produced by `Session.slice_to_journeys`. Journeys are labelled
by the traverse direction — outbound `H-O` (home→out) or homebound `O-H` (out→home) —
and the two directions are modelled by two independent agents (Section 2.5).

Crucially, the agent trains on the WHOLE journey — the leading exploratory **sorties**
as well as the terminating traverse — so, exactly like the mouse, it learns from its own
sortie exploration. The sorties are where the bulk of that experience lives (the reward
itself is only ever experienced on the terminating traverse, the one bout that reaches
the goal port). Animal and agent are then compared **on the traverses**: each traverse is
scored from value the agent accrued over the *preceding* journeys' sorties and traverses,
before that traverse's own reward (Section 2.5, "readout before reward"). So "the model
learns from the sorties" and "we compare the traverses" are two separate steps, in that
order.

### 2.2 Corridor agent (`manhattan_maze/rl_model.py`)

- **State**: corridor index (the animal's current corridor).
- **Action**: a step to an adjacent corridor (edges of `Mask.corridors_adj_mat`).
- **Reward**: $+1$ on entering the direction's goal corridor, $0$ otherwise.
- **Update**: off-policy temporal-difference TD(0),
  $$Q[s,a] \;\leftarrow\; Q[s,a] + \alpha\left(r + \gamma \max_{a'} Q[s',a'] - Q[s,a]\right),$$
  with $\gamma = 0.9$, $\alpha = 0.5$. Training replays the animal's own corridor
  sequence for *every bout of the journey* — the leading exploratory sorties and the
  terminating traverse alike — so the agent learns from the same sortie exploration the
  mouse performed; only true graph edges update $Q$ (the corridor repeats at bout seams,
  where the animal exits at a port, are skipped).
- **Readout**: a hybrid greedy/random-walk rollout from start to goal, scored by the
  same non-decreasing-distance rule used for the empirical corridor error
  (`analysis.localize_distance_seq`): a step is an error if it does not reduce distance-
  to-reward, attributed to the departing corridor. Errors are pooled over rollouts into
  a per-distance rate.

### 2.3 Turn agent (`manhattan_maze/rl_model.py`, turn-agent section)

- **State**: maze hole (9 on Mask A).
- **Action**: allocentric heading $\in \{N, S, E, W\}$; table $Q[\text{hole}, \text{dir}]$.
- **Transitions come from the animal's data, not a maze map.** Consecutive hole
  crossings give $(\text{hole}, \text{dir}) \to \text{next hole}$; a bout's final crossing
  transitions to that bout's ending port (`bout_type[-1]`: `O`→out, `H`→home). Reward
  $+1$ is experienced when a crossing lands on the direction's goal port. Because the
  correct action at each hole is the unique shortest-path move, its value
  $\sim \gamma^{\,\text{distance-to-goal}}$ is strictly the highest at every hole, so
  wrong actions that bootstrap off other holes never fool the greedy readout — no
  wall/dead-end classification is required.
- **Update**: same TD(0) rule, $\gamma = 0.9$, $\alpha = 0.5$.

### 2.4 Turn extraction: `get_hole_decisions` vs `get_allocentric_turns`

The turn agent must see the heading taken at **every** hole crossing, including
straight-through passes. The existing `Bout.get_allocentric_turns` records a hole only
where the trajectory *changes direction* (a turn), so it misses passes.
`utils.get_hole_decisions` / `Bout.get_hole_decisions` (added for this model) record the
chosen heading at every crossing. This matters because it makes the reward signal well
defined: with the passing-inclusive extraction, the mouse's **last** departure from each
shortest-path hole during a completed traverse is guaranteed to be the correct direction
(verified: 288/288 hole-traverses for the prototype animal, versus 58/288 and 22/288
mislabelled with the turns-only extraction).

### 2.5 Readout scoring, ordering, and independence

- **Turn readout — approach-conditioned first-turn error** (matches the published turn-
  error metric; `Mask.correct_approach_map`). Marching the shortest-path holes, at each
  hole the approach axis fixes the decision to the two *perpendicular* headings, exactly
  one of which is correct, so chance is $0.5$. The agent chooses greedily when its two
  candidate $Q$ values differ, else scores chance. The march is fixed (a wrong choice
  does not derail it), and only the choice is stochastic, so the per-hole error is the
  exact expectation $\{0 \text{ learned-correct},\, 1 \text{ learned-wrong},\, 0.5
  \text{ unlearned}\}$ — no Monte-Carlo rollouts.
- **Readout before reward.** For each journey the error is read out *before* the agent
  trains on that journey. So the score for traverse $b$ reflects only value the agent
  accrued over journeys $1..b-1$ — their leading exploratory **sorties** and their
  rewarded traverses — and never traverse $b$'s own reward. This matches how the animals
  are scored — a traverse's turns are committed before its reward is collected — and it
  makes traverse 1 exactly chance (no reward experienced yet; the sorties before the first
  reward, being unrewarded, teach a model-free agent nothing — Section 5). (Reading out *after* each traverse's reward instead credits the agent with the
  current reward and starts the curve below chance; see Section 6.)
- **Two independent per-direction agents.** Each direction is learned in isolation from
  its own reward. A single hole-only $Q$ shared across directions is *not* a valid
  directional learner: the correct turn at a hole differs by direction (e.g. at
  $(3,5)$ outbound-correct is N, homebound-correct is W), so a shared table either
  conflates the two goals (its greedy policy degrades to "go to the nearest port") or
  must be conditioned on direction — which is exactly the two separate agents. Empirically
  a shared both-ports model yields a chaotic, non-monotone outbound readout, confirming
  model-free RL cannot transfer between directions.

### 2.6 Cohort aggregation

Per animal and direction we obtain a $(\text{position} \times \text{traverse})$ matrix;
positions are ordered close→far from reward. Matrices are NaN-padded to a common width
(25 traverses) and averaged across animals with `np.nanmean`, mirroring
`analysis.hole_error_rate_by_direction` / `analysis.cohort_position_error_rate`
(`gen_rl_simulation.py`, `gen_rl_turn_simulation.py`; 25 animals per direction).

## 3. The figure

`error_propagation_supp` is a 2×3 panel grid. Rows are the two metrics — **A** corridor
error by distance-to-reward, **B** per-hole turn error. Columns are **animal outbound**,
**animal homebound**, and a single **model-free RL** column, with a dashed vertical
divider separating the animal block from the RL column. One colour-coded line per path
position (dark = close to reward), using a single viridis colour code shared across all
panels (colour = distance-to-reward, the same quantity everywhere) and summarised by one
colorbar on the far right. All panels share a common y-axis top (0.6); the early turn
peaks that exceed it are deliberately clipped.

- The two animal columns use the empirical cohort curves with light smoothing
  (moving-average window 3), chosen small enough to preserve first-traverse detail
  (Section 4b) yet tame per-position noise.
- The single RL column is the **analytic prediction** (Section 5), which is
  *direction-independent*, so one column serves both directions — a deliberate encoding
  of claim 3 (a model-free learner treats the directions as separate problems and cannot
  produce a direction difference). Its x-axis is truncated to ~10 traverses because the
  staircase resolves the whole 9-position path by then.

The intended reading: the RL column steps down back-to-front from chance, while the
animal columns fall roughly in parallel and start (on traverse 1) already below chance
at several positions.

## 4. Why some lines are flat

**(a) The corridor start corridor is flat at 0 — for both animals and the model.**
The far position of the corridor row ($d=9$) is the **start corridor** (home corridor 5
outbound, out corridor 16 homebound). It is a forced one-way dead end: its neighbour
list has a single entry (the one corridor leading into the maze), because the other side
is the port. A walker there has no choice; its only move necessarily *reduces* distance-
to-reward and is scored correct. So that position is $0$ from traverse 1, independent of
learning — for the model (single-neighbour state) and for the animals (empirically
$E=0$ at $d=9$ across all 25 traverses, both directions). It is pinned to $0$ in the RL
column (`dead_end_last` in `analytic_rl_staircase`) rather than drawn as a decision that
"learns last", because it is not a decision. The turn row has no such position: all 9
holes are genuine two-way turns.

**(b) The RL lines are step functions.** Each RL position sits flat at its chance level
until the reward frontier reaches it, then drops to $0$ and stays there. Learning per
position is effectively all-or-none: once value has propagated back to a position, the
greedy readout selects the correct action there from then on. The flat-at-chance segment
before onset is the honest statement that the agent has no information about that
position yet.

## 5. Why the prediction is analytic and deterministic

Three facts collapse the trained simulation to a closed form:

1. **Unrewarded exploration teaches nothing.** Sorties never reach a port with reward,
   so before the first rewarded traverse every $Q$ is $0$ and every TD target is $0$:
   no update changes the table. The agent therefore acts at chance on traverse 1
   regardless of how much it explored.
2. **TD(0) propagates reward exactly one position per rewarded traverse.** Processing a
   traverse forward, only the reward-adjacent position's value is updated from the
   reward on that pass; the next position back is updated on the next traverse, and so
   on. The low-error frontier advances one step per rewarded traverse.
3. **The readout is deterministic.** The turn readout is greedy on the *ordering* of two
   candidate values, and one experience of the correct action on a valued path orders it
   above the (still-zero) alternative — so the per-position error is a deterministic
   function of how far the frontier has advanced, with no dependence on the discount
   $\gamma$, the learning rate $\alpha$, or any random seed.

Combining these, the model-free prediction for a genuine decision position at
distance-to-reward $d$ on traverse $b$ is
$$E_{\text{RL}}(d, b) \;=\; 0.5 \cdot \mathbb{1}[\,b \le d\,],$$
i.e. chance ($0.5$) for the first $d$ traverses and $0$ thereafter; the corridor dead-end
position ($d=9$) is $0$ for all $b$. On traverse 1 every position is at chance; the
nearest decision ($d=1$) resolves on traverse 2, and the farthest ($d=8$) on traverse 9.

This closed form is what the figure draws. The trained per-animal simulations
(both the corridor and turn agents in `rl_model.py`) exist as **validation**, not as the plotted data:
the turn cohort reproduces the staircase exactly (e.g. homebound onsets
$[0,1,2,\dots,8]$ before the readout-before-reward shift), and the corridor cohort
reproduces it except at the dead end and its random-walk baseline (Section 6).

**Hyperparameter independence.** Because the readout compares only the *ordering* of learned
values, the staircase is invariant to the discount $\gamma$ and the learning rate $\alpha$: any
$\gamma < 1$ and any $\alpha > 0$ give the same prediction. The same argmax invariance holds for
the related Mask-D self-play comparison (`fig:algo`), where the bottleneck-choice ramp is set by
the stochastic self-play coverage of the bicliques rather than by $\gamma$ or $\alpha$. These RL
hyperparameters are therefore omitted from the Methods (so $\gamma$ and $\alpha$ remain manuscript
symbols only for the endotaxis gain and goal-learning rate; see `docs/notation_guide.md`).

## 6. Chance levels and the 0.44 detail

- **Turn chance is exactly $0.5$.** Approach conditioning leaves two reachable turns at
  each scored hole, one correct.
- **Corridor per-decision chance is $0.5$** — on a linear track each interior corridor
  has two neighbours (toward / away from reward), so a random step is $50/50$.
- **The trained corridor's first-column *mean* is $\approx 0.44$, not $0.5$.** This is
  not the per-decision chance; it is the average of eight genuine two-way corridors at
  $0.5$ and the single forced dead-end at $0$: $(8 \times 0.5 + 1 \times 0)/9 = 0.44$.
  The figure's corridor column draws the per-decision chance ($0.5$) and pins the dead
  end at $0$ separately, so it does not inherit this dilution.
- **Readout ordering and the earlier $0.44$ artifact.** With the (rejected) readout-
  *after*-reward ordering, the turn first column also read $\approx 0.44$ — because the
  first traverse's reward had already been folded into training, so the reward-adjacent
  hole was solved and the column was $(8 \times 0.5 + 1 \times 0)/9$. Reading out before
  each traverse's reward restores true chance ($0.5$) on traverse 1 and is the ordering
  used throughout.

## 7. Condensed text for the manuscript

**Methods (adapt/trim).** *As a null model we simulated a tabular, model-free
Q-learning agent (TD(0)) trained on each animal's own
Mask-A trajectories — its exploratory sorties and completed traverses — with reward
delivered only on reaching a port; separate agents learned the outbound and homebound
directions. Corridor states were corridors and turn
states were holes (actions = allocentric headings), with transitions taken from the
animal's visited sequence. Error was read out before each traverse's reward — matching
how the animals are scored — and, for turns, using the same approach-conditioned first-
decision metric (chance 0.5). Because an unrewarded excursion cannot update a model-free
value and TD backs the reward up exactly one position per rewarded traverse, the
prediction is the deterministic backward staircase $E_{\text{RL}}(d,b)=0.5\cdot
\mathbb{1}[b\le d]$, independent of the discount and learning rate (the forced dead-end start
corridor is 0 throughout); the trained simulations reproduce it.*

**Discussion (adapt/trim).** *The animals' error did not fall in the back-to-front
staircase a model-free learner predicts. Instead all path positions improved roughly in
parallel, several positions were already below chance on the first rewarded traverse
(latent learning during unrewarded exploration, which a model-free value cannot
acquire), and the two travel directions improved together rather than as the two
independent, single-ended problems a model-free learner treats them as. Together these
argue that error reduction here reflects an integrated, bidirectional representation of
the path rather than local, reward-gated value propagation.*
