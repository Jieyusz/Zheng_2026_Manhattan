# Manhattan Maze

Analysis code for *Rapid spatial cognition in mice, with and without neocortex and hippocampus* (Zheng et al., 2026).

Mice navigate a two-floor 11×11 "Manhattan" maze (horizontal corridors on the
bottom floor, vertical corridors on the top floor, connected by holes). This
repository turns the recorded trajectories into the manuscript's learning-curve,
path-similarity, memory, and navigation-model figures.

> Status: figures are reproducible from the included figure data for the manuscript. Trajectory processing code is included, but raw or processed trajectory data are not included at this current stage. 

For the bout/traverse naming conventions used by the figures and the `figure_data`
keys see [`docs/usage.md`](docs/usage.md); for input data schemas and units see
[`docs/data_contracts.md`](docs/data_contracts.md); for
the manuscript equations, symbols, and units see
[`docs/notation_guide.md`](docs/notation_guide.md). For the learning-curve fits and
the authoritative per-curve sample sizes see
[`docs/curve_fit_summary.md`](docs/curve_fit_summary.md); for the model-free-RL null
model behind the error-propagation figure see
[`docs/rl_error_propagation.md`](docs/rl_error_propagation.md).

## Repository structure

```
manhattan_maze/            # analysis package (importable)
  __init__.py              # public API: DataLoader, Mask, MaskDSpecial, MaskDSpec, Trajectory, Session, Bout
  mask.py                  # Mask + MaskDSpecial (maze geometry / graph; MAZE_SIZE default)
  mask_d.py                # MaskDSpec: hardcoded Mask-D display topology (biclique groups,
                           #   bottleneck / shortest-path corridor indices, plot order + colors)
  trajectory.py            # Trajectory + Session + Bout (data objects)
  data_loader.py           # DataLoader: loading + QC/segmentation pipeline
  utils.py                 # pure computation: geometry, graph, metrics, curve fitting, stats, I/O
                           #   (facade re-exporting analysis/bootstrap/curve_fit/geometry/
                           #    graph/io/similarity/stats/plot_* submodules)
  plot_utils.py            # visualization helpers + set_style()
  endotaxis.py             # endotaxis navigation model
  random_walk.py           # first-order Markov walker: completion time + corridor errors
                           #   (non-learning baseline)
  rl_model.py              # model-free RL agents (corridor + turn) + analytic staircase
                           #   (non-learning null for the error-propagation figure;
                           #    see docs/rl_error_propagation.md)

scripts/
  config.py                # shared script config: paths, DataLoader kwargs, curve-fit specs
                           #   (param names + LaTeX), GENOTYPES, figure-label conventions, colors
  gen_*.py                 # generate figure data into data/figure_data/ (one producer per figure
                           #   group; each documents its "Saved keys" data contract in its docstring)
  gen_curve_fits.py        # central bootstrap curve fitting + two-day ratio CIs (runs after producers)
  plot_*.py                # render manuscript figure PDFs from figure data
  batch_generate_figure_data.py   # run all gen_*.py in the correct order
  report_panel_n.py        # reviewer support: per-panel sample sizes (not part of the pipeline)
  update_overleaf_plots.py # render every plot_*.py into figures/paper_figures/ (or an external -s dir)

data/
  figure_data/             # figure-ready arrays/tables -- the payload that makes every
                           #   figure renderable without trajectory data  [473 files]
  masks/                   # maze hole geometry (holes_*.npy)
  manhattan_metadata_published.csv     # metadata for the analysed recordings
  Top_view_labeled.png     # maze photo, read directly by scripts/plot_oa_supp.py

docs/                      # usage.md, data_contracts.md, notation_guide.md, ratio_ci_method.md,
                           #   curve_fit_summary.md, rl_error_propagation.md
                           #   (panel_n_report.md is generated by scripts/report_panel_n.py)
tests/                     # regression tests (pytest)
figures/
  paper_figures/           # the manuscript figure PDFs + MRI/HSV PNGs
  pdf/                     # scratch render target for individual plot_*.py runs  [gitignored]
```

## Installation

Requires Python 3.12.

```shell
conda create --name m_maze python=3.12
conda activate m_maze
conda install --file requirements.txt    # or: pip install -r requirements.txt
```

All commands below assume the `m_maze` environment is active.

## Data requirements

**Included.** Everything needed to render the manuscript figures:

- `data/figure_data/` — the figure-ready arrays and tables every `plot_*.py` reads.
- `data/masks/` — maze hole geometry (`holes_*.npy`).
- `data/manhattan_metadata_published.csv` — metadata for the analysed recordings.
- `data/Top_view_labeled.png` — maze photo, read directly by `plot_oa_supp.py`.

**Not included.** The behavioral trajectory data — the reduced per-frame cell-position
recordings, the per-recording reward and room-status files, and the upstream DeepLabCut
pose tracking and videos they were decoded from. The trajectory-processing code that
consumes them is included, but the data is not distributed at this stage.

Consequently `scripts/gen_*.py` and `batch_generate_figure_data.py` **cannot run from
this checkout**; they are included as the provenance of `data/figure_data/`, not as
runnable steps. Rendering a figure does not need them — every `plot_*.py` reads
`data/figure_data/` directly.

See [`docs/data_contracts.md`](docs/data_contracts.md) for the schema and units of every
data object that does ship.

## Supplementary video clips

The annotated behavioral clips in the manuscript's supplementary videos are built from the
raw behavioral videos and DeepLabCut tracking, neither of which is distributed. That tooling
is therefore not included here and is not part of the figure pipeline.

## Reviewer support: per-panel sample sizes

> **Reviewer-support tooling — not part of the reproducible figure pipeline.**

`scripts/report_panel_n.py` derives the number of animals (*n*) behind each panel of
the six main figures — plus a Methods-level "Subjects" summary — directly from the
`data/figure_data/` caches and the metadata CSV, rather than from hand-counted values. It emits **aggregate counts only** (no per-animal identifiers)
and writes a human-readable report to [`docs/panel_n_report.md`](docs/panel_n_report.md),
also printing a cross-check divergence summary to stdout.

It reads the included `data/figure_data/`, so it runs directly from a fresh clone:

```shell
cd scripts
python report_panel_n.py     # writes docs/panel_n_report.md
```

## Tests

```shell
pytest tests/
```

The tests pin golden values for the load-bearing scientific contracts
(coordinate encoding, graph distances, Mask A geometry, bout construction, turn
error, learning-curve models, the Mask-D adjusted-Jaccard correction,
random-walk completion times / corridor errors, and the model-free-RL
error-propagation staircase), plus a smoke test that renders every `plot_*.py`
from the included figure data.

## Reproducibility

- **Random seeds.** Each `gen_*.py` that samples (e.g. example-animal
  selection) exposes a `--seed` argument with the published default. Any seed
  produces qualitatively identical figures. The allocentric-turn-sequence
  schematic (`plot_utils.plot_allocentric_turn_seq`) likewise accepts a `seed`
  for its cosmetic arrow jitter; the jitter is purely visual and does not change
  which turns are drawn.
- **Caches.** `data/figure_data/` is a cache, included here precisely because rebuilding
  it requires the trajectory data, which is not distributed — do not delete it expecting
  a rebuild.
- **Figure caches hold no live objects.** Example sessions and traverses are stored
  as flat `.parquet` tables (`manhattan_maze.plot_data` builds them; the plotting
  methods and the plot scripts share one extractor per panel), so moving a class
  cannot break a cache. The single exception is `masks.pkl`, listed in
  `manhattan_maze.io.R8_PICKLE_ALLOWLIST` because `Mask` objects are *called* as
  objects downstream; delete `data/figure_data/` and rerun
  `batch_generate_figure_data.py --overwrite` after moving `Mask`.
  `save_modular_data` warns on any non-allowlisted key that pickles a live object.
  Because keys are filename stems, `load_all_figure_data` also raises if it finds the
  same key in two formats — delete the stale file rather than guessing which wins.
- **Model conventions (see `docs/notation_guide.md`).** Both the
  traverse-duration and turn-error learning curves use the same exponential
  model `value(b) = ∞ + (0 − ∞)·exp(−rate·(b−1))`, indexed from `b = 1`; the
  learning-rate parameter is `δ` (duration, stored `delta`) / `ε` (turn error,
  stored `epsilon`), and residuals are `ξ^D`/`ξ^E`. The turn error rate is
  **approach-conditioned** (a hole crossing is scored only when the mouse enters
  on the shortest-path corridor, giving a 0.5 chance level); the older
  `include="all"`/`"first"` scoring is deprecated. The adjusted-Jaccard
  path-similarity correction (subtracting guaranteed transitions) is
  **Mask-D-specific**; other masks use standard Jaccard.

### Verifying outputs match the published version

1. `pytest tests/` — all regression tests pass.
2. Re-render the figures from the included caches: `cd scripts` then the relevant
   `plot_*.py` (or `python update_overleaf_plots.py` for all of them).
3. Compare the resulting PDFs to those in `figures/paper_figures/`. Curve values and
   statistics match within floating-point tolerance; example-animal panels are
   qualitatively identical for any `--seed`.

Regenerating `data/figure_data/` itself is not possible from this checkout — it requires
the trajectory data, which is not distributed.
